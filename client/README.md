# wardrobe-client

`wardrobe-client` is the pure Rust client for server-backed Wardrobe databases. It connects to a running `wardrobe-server` over TCP or a Unix socket and does not include the embedded storage engine.

Use [`wardrobe-embedded`](https://crates.io/crates/wardrobe-embedded) when the application needs to open Wardrobe data directly from the local filesystem.

## Installation

```text
cargo add wardrobe-client
```

## Certificate-Authenticated TCP Connection

Wardrobe servers use client certificates in managed or external security mode. Pass the client profile generated by `wardrobe-server bootstrap-admin` or `wardrobe identity create`:

```rust
use wardrobe_client::{OperationFilter, OperationOptions, WardrobeClient};

fn main() -> std::io::Result<()> {
    let client = WardrobeClient::open_with_profile(
        "wardrobe://localhost:24842",
        "./profiles/adminuser/profile.toml",
    )?;

    let books = client.read(
        OperationFilter::new("catalog", "public", "book"),
        OperationOptions::default(),
    )?;

    println!("books: {}", books.count);
    Ok(())
}
```

The profile identifies the CA certificate, client certificate, and client private key. Relative certificate paths are resolved from the directory containing `profile.toml`.

See the repository's [managed certificate setup](https://github.com/totalknowledge/wardrobe#step-by-step-managed-connection-setup-with-locally-generated-certificates) for local certificate generation and server registration.

## Connection Targets

- `wardrobe://host:port` connects over TCP.
- `wardrobe://host` connects over TCP using port `24842`.
- `wardrobe+unix:///path/to/wardrobe.sock` connects over a Unix socket.

Use `WardrobeClient::open_with_profile` for certificate-authenticated TCP, `WardrobeClient::open_with_tls` for explicit certificate paths, and `WardrobeClient::open` for Unix sockets or explicitly unsecured localhost TCP.

## Operations

`WardrobeClient` exposes the canonical `read`, `upsert`, `delete`, `inspect`, `count`, `compact`, `create`, `alter`, `drop`, `backup`, `restore`, `grant`, `revoke`, and `status` operations.

API documentation is available on [docs.rs](https://docs.rs/wardrobe-client).
